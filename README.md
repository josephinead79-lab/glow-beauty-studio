# Glow Beauty Studio 💄✨

Welcome to Glow Beauty Studio!

Glow Beauty Studio is a beautiful and elegant salon website designed to showcase beauty services and help customers connect with the salon.

## Our Services
- Professional Makeup
- Nail Care
- Facials
- Lash Extensions

## Features
- Beautiful and responsive design
- Home, About, Services and Contact sections
- Service images
- WhatsApp contact link

## Technologies Used
- HTML
- CSS

## Project Goal
The goal of this project is to create a simple, attractive and user-friendly website for a beauty salon.
